# Memorandum

A clean, offline-first Android note-taking app built with Jetpack Compose and Material 3. It's designed to be simple, fast, and completely private—no cloud syncing, no tracking, just your notes.

## What it does

* **Core Note-Taking:** Create, edit, and search notes in real-time. Auto-save handles your drafts in the background.
* **Organization:** Pin your favorites, switch between List and Grid layouts, and use long-press for bulk selection.
* **Trash & Recovery:** Accidentally deleted something? Soft-delete sends it to the Trash where it can be restored.
* **Import / Export:** Easily back up or move your data using standard `.txt` files.
* **Modern UI:** Full support for Light/Dark modes and Material You dynamic theming.
* **Languages:** Fully localized in English, Romanian, Ukrainian, Spanish, and Portuguese.

## Tech Stack

Built using modern Android development tools and standards:
* **Language/UI:** Kotlin, Jetpack Compose, Navigation Compose
* **Architecture:** MVVM + Clean Architecture principles
* **Dependency Injection:** Hilt
* **Local Storage:** Room Database, DataStore
* **Concurrency:** Coroutines & Flow
